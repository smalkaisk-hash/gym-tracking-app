If you followed a link from inside the app

That is a bug worth reporting. Note the screen you came from, what you clicked, and roughly when it happened, then send those details to the contact address on the FAQ page. Include the address shown in your browser's location bar — it tells us exactly which link is wrong so it can be fixed.
